# ⚡ AI Speed Extension

A browser extension that significantly improves ChatGPT performance by reducing lag in long conversations using intelligent message rendering and API optimization.

---

## 🚀 Features

* ⚡ **Fast Mode**

  * Displays only recent messages
  * Reduces DOM load
  * Improves speed and responsiveness

* 📜 **Full Mode**

  * Loads complete conversation
  * Toggle anytime from popup

* 🎛 **Dynamic Message Control**

  * Adjustable visible messages using slider
  * "Load More" button for progressive reveal

* 🧠 **Performance Optimization**

  * Reduces CPU usage
  * Lowers RAM consumption
  * Minimizes unnecessary re-renders

* 🎨 **Clean UI Enhancements**

  * Floating mode badge
  * Smooth button interactions

---

## 🧠 How It Works

* Intercepts ChatGPT conversation API responses
* Limits the number of messages rendered in DOM
* Uses DOM manipulation to hide older messages
* Provides user control over visibility and mode

## 📦 Installation (Manual)

1. Download this repository as ZIP
2. Extract the folder
3. Open browser and go to:

   ```
   brave://extensions/
   ```

   or

   ```
   chrome://extensions/
   ```
4. Enable **Developer Mode**
5. Click **Load unpacked**
6. Select the project folder

---

## ⚙️ Usage

* Toggle between **Fast Mode** and **Full Mode** using popup
* Adjust visible messages using slider
* Click **Load More** to reveal older messages
